# Tech Stack Standard

## Frontend
- HTML5 semantic markup
- TailwindCSS 4.0+ (utility-first CSS)
- Vanilla JavaScript (no framework)

## Hosting
- Nodion (European PaaS, Buildpack deployment)

## Tooling
- Node.js 22 LTS (for local dev server and build tools)
- npm (package manager)

## Image Formats
- WebP with PNG/JPG fallback
- Lazy loading for below-the-fold images

## No Framework Policy
This is a static site. Do not introduce React, Vue, Svelte, or any SPA framework unless explicitly approved.
