# Product Mission

## Vision

Portfolio website that faithfully represents the SporckLiving brand online, converted from an Adobe XD prototype into a fast, accessible, responsive website.

## Problem

The design exists as an Adobe XD prototype but has no live web presence. A production-ready website is needed that matches the design precisely while being performant and accessible.

## Target Users

- Visitors to the SporckLiving portfolio/website
- Potential clients or contacts browsing the portfolio

## Solution

A lightweight static website built with HTML, TailwindCSS, and vanilla JavaScript — deployed on Nodion (European hosting). No heavy framework overhead, optimised for speed and accessibility.

## Design Source

- **Adobe XD Prototype**: https://xd.adobe.com/view/acbc41db-9a55-4613-b918-65a734308669-f9ef/
- All visual design tokens (colours, typography, spacing, layout) are derived from this prototype
