# Product Roadmap

## Phase 1: Design Extraction (Current)

- Navigate Adobe XD prototype via Playwright
- Screenshot every unique screen/artboard
- Extract all design tokens: colours, fonts, spacing, layout
- Download visible images/assets
- Generate developer specs (design handoff)

## Phase 2: Website Build

- Build responsive HTML pages matching XD design
- Implement TailwindCSS styling with extracted design tokens
- Add vanilla JS for interactions (navigation, animations, etc.)
- Optimise all images for web
- Ensure mobile responsiveness across breakpoints
- Add meta tags, Open Graph tags, favicon

## Phase 3: Quality & Accessibility

- WCAG 2.1 AA accessibility audit and fixes
- Cross-browser testing
- Performance optimisation (Core Web Vitals)
- Design critique and usability review

## Phase 4: Deployment

- Create GitHub repository
- Push all files with clean folder structure
- Configure Nodion deployment (Buildpack or Dockerfile)
- Set up custom domain (if applicable)
- Document deployment process in README

## Current Status

**Phase 1** — Ready to begin design extraction from Adobe XD prototype.
